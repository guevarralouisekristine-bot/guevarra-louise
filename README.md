# Career Pathways: System Administration

A responsive student portfolio introducing system administration careers, from entry-level IT support to systems engineering. The site covers role responsibilities, career progression, foundational skills, and commonly used tools in a light-pink and black design.

## Run locally

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create and preview a production build:

```sh
npm run build
npm run preview
```

## Project structure

- `src/App.jsx` — page content, pathway and resource data, and responsive navigation.
- `src/App.css` — page layout, component styling, and responsive breakpoints.
- `src/index.css` — global styles, typography, and theme colors.

The portfolio is a static React site and does not require a database, login, or server-side setup.
